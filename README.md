# 钙钛矿前驱体配方计算器

**MK Design** · Perovskite Precursor Calculator

![MK Design 计算器标识](docs/branding.png)

![简约单页工作台](docs/workspace.png)

一个面向钙钛矿太阳能电池实验的中文离线配液工具。HTML、CSS、JavaScript 全部包含在一个文件中，无 CDN、在线字体或远程接口。

## 直接使用

1. 下载 [`perovskite_calculator.html`](perovskite_calculator.html)（在 GitHub 文件页使用 **Download raw file**，或下载仓库 ZIP）。
2. 用 Windows 上的 Chrome / Edge 打开，无需安装软件、运行服务器或联网。
3. 点击“＋ 选择药品”，勾选主盐或添加剂；在紧凑表格内填写比例，并在上方设置浓度、片数、单片用量及冗余。

桌面端采用单页工作台：1366×768 下可同屏展示六种药品及对应结果；更短窗口或更多药品按可用高度分页，药品与结果同步切换。药品详情（⋯）、参考基准与备注（设置）、药品库及完整配液单按需打开，不挤占主界面。手机端采用纵向布局。

点击 **＋ 新建药品**，只输入名称和摩尔质量即可保存到药品库或加入配方；化学式与 Pb / Sn 原子数为可选项。

## 主要功能

- 15 种预设前驱体药品；支持任意自定义药品和可编辑摩尔质量。
- 主盐按参考单元 mol% 或 eq 输入；额外添加剂支持 mol%、mg/mL、wt% 和固定 mg。
- mol% 明确相对于主盐 Pb、Sn、Pb+Sn、参考化学式单元或指定主盐。
- 理论消耗、含冗余的建议配液体积、质量目标、天平取整偏差及实际当量实时更新。
- 0.01 mg / 0.1 mg 天平分辨率，微量称量与移液提示。
- 固体称量或母液加入，支持 mol/L 与 mg/mL 浓度；母液载体纳入溶剂核算。
- 名义溶剂体积与严格最终溶液体积定容两种模式。
- 本浏览器保存多份配方，JSON 完整备份与恢复、CSV 导出、A4 配液单打印。
- 适配电脑、普通笔记本和手机；全部计算在本机运行。

## 计算约定

`n_ref = C × V(μL) / 10⁶`；`n_i = n_ref × eq_i`；`m_i(mg) = n_i × MW_i × 1000`。

主盐 **100 mol% = 1 eq**，相对于用户定义的参考化学式单元。应用依据明确输入的盐及比例计算，不从 ABX₃ 目标化学式推断盐类组合。添加剂额外加入，不自行扣减主盐。

wt% 的质量分母在界面中明确指定。严格定容模式下，固体溶解后的最终体积不等于预加溶剂体积，不能照搬名义模式的固定加入量。详细算法与原子量来源见应用内的“计算说明”。

以 1.2 mol/L、10 片、50 μL/片、20% 冗余、100 μL 固定损耗及 FAI / PbI₂ 各 1 eq 为例：建议体积 **700 μL**，FAI **144.4548 mg**，PbI₂ **387.2484 mg**（均为取整前目标）。

## 保存与迁移

“保存配方”保存在当前浏览器的 localStorage。在“更多”中点击“导出 JSON”可保存当前配方、已保存配方库及自定义药品库，下次“导入 JSON”即可完整恢复。换浏览器、移动文件或清理浏览器数据前建议先备份 JSON。

## 验证

应用内点击“运行内置自检”可执行 **21 项**确定性检查。开发者可使用 Node.js 运行同一组计算测试，无第三方包：

```sh
node tests/run-tests.cjs
```

GitHub Actions 会自动执行计算自检及离线资源检查。[自检记录](自检记录.md)列出了交互验证范围与验证边界。
