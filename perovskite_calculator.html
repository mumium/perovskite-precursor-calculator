理论值按器件消耗体积，建议值按含冗余的整批体积。固定 mg 按每批保持不变。按无水、100% 有效成分计算；纯度、水合状态或溶剂化物请通过实际 MW 或有效浓度明确。

计算基准与使用说明

1. 从药品库选择主盐，再输入比例。主盐 100 mol% = 1 eq，相对于自定义的参考化学式单元。多阳离子、I/Br、Pb/Sn 配方均通过明确输入各盐的当量表达，不从 ABX₃ 目标式猜测。

V_theory = 片数 × μL/片
V_batch = V_theory × (1 + 冗余%/100) + 固定损耗
n_ref = C × V(μL) / 10⁶
n_i = n_ref × eq_i；m_i(mg) = n_i × MW_i × 1000

2. mol% 添加剂相对基准仅统计主盐：Pb / Sn / Pb+Sn 按每个盐分子中金属原子数累计；也可相对参考单元或指定主盐。添加剂不进入这些基准，不自动扣减主盐。

3. mg/mL × 本批名义体积(mL)。wt% 支持 m_add/m_主盐干质量、m_add/m_指定主盐或 m_add/手动输入的基准质量；这里的百分数不是占包含添加剂的总质量分数。固定 mg 为每批绝对量，理论列与建议列不按体积缩放。

4. 母液：mol/L 按 n/c 换算体积，mg/mL 按 m/c 换算；体积均显示 μL。同一条药品仅采用固体或母液一种方式。若有意分次或用两种途径加入，可另建条目，但应自行核对重复量。

5. A 模式：建议体积为实验名义溶剂体积（含母液载体），各溶剂目标体积减去对应母液体积得到补加量，假设液体体积可加；此处 C 为名义投料浓度。B 模式：以最终溶液体积定容，先用适量混合溶剂溶解，再定容至目标；不能由质量推算固体溶解后的体积变化，也不能保证最终溶液中的溶剂体积比。

6. 建议质量按最近的天平刻度四舍五入，偏差 = (取整值/未取整值 − 1) × 100%。显示“实际 eq”为按建议取整质量折算的当量；实际 mol% 的主盐分母也按取整后质量重算。母液项按未取整移液目标量折算，切换母液浓度单位会自动换算数值。实际实测称量误差未包含。

7. 点击“＋ 新建药品”，只需输入名称和摩尔质量即可保存到药品库或直接加入主盐；化学式与金属原子数可选，自定义药品随 JSON 一起保存。浏览器自动暂存当前草稿，命名后“保存配方”可多配方管理。导出 JSON 包含当前完整配方、已保存配方和药品库；下次导入可完整恢复。浏览器清理数据、换浏览器或移动文件可能影响 localStorage，JSON 文件可独立备份和迁移。

8. 药品库使用的约定原子量：H 1.008、C 12.011、N 14.007、O 15.999、F 18.998403163、Cl 35.45、Br 79.904、I 126.90447、Cs 132.90545196、Pb 207.2、Sn 118.710、S 32.06。MW 先按原子数计算，再四舍五入到 0.01 g/mol 作为默认采用值，以匹配验收示例（FAI 171.97、PbI₂ 461.01）。Pb 采用常用约定值 207.2；天然同位素组成会产生变化，显示小数位不代表材料批次的真实精度。
